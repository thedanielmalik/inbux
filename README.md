# Inbux

Inbux is an email marketing workspace designed around deliverability first.

## V1 direction
- Campaigns
- Contacts and list hygiene
- Audience segmentation
- Inbox Health
- Templates
- Automations
- Reporting
- Provider-backed email delivery (planned)

## Product principle
Inbux should maximize legitimate inbox placement through authentication, reputation protection, suppression, list hygiene, controlled sending and transparent analytics. It must not promise guaranteed inbox placement.

## Stack
Next.js + React + TypeScript + Recharts.
